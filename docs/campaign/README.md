# Campaign documents

The pre-launch campaign documents (verbal brand kit, brief, roadmap, question guide and each phase's output) are written in Spanish and live in the claude.ai Project **"OPTA"**, folder `campaign/`. They are not in this repo. See `docs/decisions/0002-campaign-documents-live-in-the-claude-project.md`.

## How to read them

Use the Projects tool, not the filesystem:

- `project_read` with the path below, or
- `project_search` with a query.

| Path in the Project | What it is |
|---|---|
| `campaign/README.md` | Index of the documents |
| `campaign/prelaunch/ROADMAP.md` | Roadmap, workstreams, decision points (G1 to G4) and risks |
| `campaign/prelaunch/00-brief.md` | Campaign brief (phase 0) |
| `campaign/prelaunch/01-guia-de-preguntas.md` | Question guide for unbiased research |
| `campaign/brand-kit-verbal.md` | Verbal brand kit: voice, lexicon, what can and cannot be claimed, microcopy, consent drafts |

If the session is not attached to the Project, say so and ask Santiago. Do not recreate or guess these documents.
